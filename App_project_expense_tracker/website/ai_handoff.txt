1. PROJECT OVERVIEW & PURPOSE
--------------------------------------------------------------------------------
This directory contains the static marketing landing site for the Expense Tracker
Android application. It highlights the app's features (private cloud sync, budget 
tracking, savings goals, debt management, multi-currency support) and provides 
direct download links (Google Play Store & direct APK).

--------------------------------------------------------------------------------

--------------------------------------------------------------------------------
3. TECHNICAL HIGHLIGHTS & DESIGN SYSTEM
--------------------------------------------------------------------------------
- Design System: Custom Vanilla CSS with CSS custom properties (:root tokens).
  - Palette: Dark Theme (#0d0e12 background) with Amber accents (#f59e0b).
  - Typography: Inter (imported via Google Fonts).
  - Components: Glassmorphic navigation header, floating phone mockups, 
    interactive card components with hover animations, scroll-reveal effects.
- Dynamic Header & Footer (nav.js):
  - Injects consistent top navigation header and footer across all HTML pages.
  - Automatically highlights the current active page link based on window location.
  - Includes scroll-reveal IntersectionObserver logic for page animations.
